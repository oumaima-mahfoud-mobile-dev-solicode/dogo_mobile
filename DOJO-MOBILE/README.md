# Dojo Mobile

Présentation Marp pour le Dojo Mobile — Dev Mobile 201.


## Structure

```
_layouts/        # Layouts Jekyll
assets/css/      # Styles personnalisés
_config.yml      # Configuration Jekyll
index.html       # Présentation Marp exportée
index.md         # Page d'accueil
stateDiagram.png # Diagramme d'état
```



## Déploiement

Le site est déployé automatiquement sur GitHub Pages via GitHub Actions à chaque push sur `main`.
